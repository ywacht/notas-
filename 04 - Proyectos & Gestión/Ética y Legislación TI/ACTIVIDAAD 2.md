5. Un programador no agrega funciones peligrosas o innecesarias solo por terminar más rápido el proyecto.
    

### 2. Privacidad y protección de datos

1. Una aplicación no debe guardar el nombre, teléfono o dirección de un usuario sin su autorización.
    
2. Una página web debe pedir permiso antes de utilizar la cámara o el micrófono del dispositivo.
    
3. Los datos personales de los usuarios deben mantenerse protegidos y no compartirse con otras personas sin autorización.
    
4. Una aplicación de salud debe evitar mostrar información médica de un usuario a otras personas.
    

### 3. Seguridad

1. Un sistema debe utilizar contraseñas y mecanismos de autenticación para evitar accesos no autorizados.
    
2. Una aplicación bancaria debe proteger las cuentas para evitar que alguien pueda robar el dinero de los usuarios.
    
3. Los desarrolladores deben corregir vulnerabilidades cuando encuentran una falla de seguridad.
    
4. Un sistema debe realizar copias de seguridad para evitar la pérdida de información en caso de un ataque o fallo.
    

### 4. Transparencia

1. Una aplicación debe explicar claramente qué información recopila de sus usuarios.
    
2. Un sitio web debe informar si utiliza cookies y para qué las utiliza.
    
3. Si una aplicación utiliza inteligencia artificial para tomar decisiones, debe explicar de manera comprensible cómo se utiliza.
    
4. Una aplicación debe informar al usuario cuando comparte sus datos con otros servicios.
    

### 5. Honestidad

1. Un desarrollador debe informar si su programa todavía tiene errores conocidos.
    
2. Si una inteligencia artificial puede equivocarse, los usuarios deben ser informados de esa posibilidad.
    
3. No se debe afirmar que un software tiene una función que realmente no posee.
    
4. Si un sistema tiene limitaciones importantes, estas deben explicarse antes de que el usuario lo utilice.
    

### 6. Equidad y no discriminación

1. Un sistema de contratación no debe rechazar automáticamente a personas por su género, edad o características personales.
    
2. Un algoritmo de reconocimiento facial debe probarse con diferentes grupos de personas para evitar resultados injustos.
    
3. Una aplicación educativa debe ofrecer las mismas oportunidades a todos los estudiantes.
    
4. Un sistema de inteligencia artificial no debe tomar decisiones desfavorables basándose en prejuicios contra un determinado grupo.
    

### 7. Propiedad intelectual

1. Un desarrollador no debe copiar el código de otra persona y presentarlo como si fuera suyo.
    
2. Si se utiliza una biblioteca de código abierto, se deben respetar las condiciones establecidas por su licencia.
    
3. Las imágenes, videos o música utilizados en una aplicación deben contar con los permisos correspondientes.
    
4. Un programador debe respetar las patentes y derechos de autor relacionados con tecnologías utilizadas en su software.
